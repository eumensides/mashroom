血红色钉菇
Chroogomphus rutilus
(Schaeff.) O.K. Mill. · 俗称「红蘑 / 松蘑 / 松树伞」
✓ 可食用 菌盖红棕至紫红色 与松属共生 孢子印深灰色 色钉菇属模式种 易与铆钉菇属混淆
中文俗名 血红色钉菇 / 血红铆钉菇 / 红蘑
分布 中国大陆（全国广布）、日本、韩国、欧洲、西伯利亚
科 / 属 Gomphidiaceae 铆钉菇科 / Chroogomphus 色钉菇属
保护等级 中国生物多样性红色名录：无危（LC）
标志结构：橘黄菌肉 菌盖红棕、红黑色至紫红色，剖开后菌肉呈鲜明的橘黄色至浅黄棕色，梅泽试剂检验呈淀粉质阳性反应，是本属重要的鉴定特征
松林共生标志种 外生菌根真菌，专性与松属（Pinus）树木根系共生，常见于油松、赤松等纯林地表，是松林生态系统的指示性物种之一
属级易混淆提醒 与近缘的铆钉菇属（Gomphidius）外形极其相似，二者主要靠菌肉颜色及化学反应区分，普通采集者需格外留意

形态特征 · 生长周期 结构标签
幼期
菌盖圆锥形至钟形，浅咖啡色至红棕色，表面光滑，湿时黏滑；菌褶尚未完全展开，青黄色，此期柄上部常有易消失的薄菌环。
成长期
菌盖渐展平，中部微凸起，色泽转为红棕至紫红色，干时略具光泽；菌柄伸长，圆柱形向下渐细，与菌盖色相近，基部带黄色；菌褶延生，稀疏，青黄色渐转紫褐色。
成熟期
菌盖完全平展，过熟后呈漏斗形，直径3–12cm，红棕、红黑色或紫红色，常有虫蛀；菌肉带红色，干后呈淡紫红色；菌柄4–16cm，稍带红色的橘黄色，实心；孢子印深灰色。
颜色 · 形状 · 气味 · 口感
颜色
菌盖红棕→红黑/紫红色 菌肉橘黄色（干后淡紫红） 菌褶青黄色→紫褐色 菌柄橘黄带红色 孢子印深灰色
形状
幼期圆锥形至钟形 成熟平展，过熟呈漏斗形（径3–12cm） 菌褶延生，稀疏，不等长 菌柄圆柱形向下渐细（4–16cm） 上部常有易消失菌环
气味
气味不明显，无特殊香气 湿时表面黏滑，干时具光泽
口感
肉质肥嫩，味道清淡 常用于炖煮，如"小鸡炖蘑菇" 耐储藏，适合干制
各部位详情
部位 形态描述
菌盖表皮 凸镜形至扁平，过熟呈漏斗形，直径3–12cm；表面棕色、红棕色至红黑色，光滑，湿润时黏滑，干燥后紫红色，常有虫蛀
菌褶 延生，稀疏，不等长，青黄色渐转紫褐色，具长圆柱状侧囊状体
菌肉 橘黄色至浅黄棕色，近柄基部带黄色，干后呈淡紫红色；梅泽试剂检验呈淀粉质阳性反应
菌柄 4–16cm，圆柱形向下渐细，稍带红色的橘黄色，实心，上部往往有易消失的薄菌环
菌环 幼期可见，成熟后多已消失，痕迹不明显
菌托 无——本种无外菌幕包裹结构，柄基无袋状或球状菌托
孢子 表面光滑，圆柱状，长14–22微米，宽4.5–7微米；孢子印深灰色至近黑色
特殊区分点 反向记忆
核心辨识四要素
  • 菌盖红棕至紫红色，湿时黏滑，与鲜黄至橘黄色的菌肉形成鲜明对比
  • 菌褶延生且稀疏，青黄色渐转紫褐色——延生特征是与许多褶菌区分的重要参考
  • 菌肉在梅泽试剂中呈淀粉质阳性反应（变蓝），这是区分色钉菇属与近缘铆钉菇属的关键化学特征
  • 专性与松属树木共生，几乎只见于松科纯林或混交林地表，脱离松树难觅其踪
⚠ 采集提示：与铆钉菇属的形态易混淆
  • 色钉菇属（Chroogomphus）与铆钉菇属（Gomphidius）同属铆钉菇科，外形特征极其相似，仅凭肉眼有时很难区分，需借助菌肉颜色及化学反应等特征综合判断
  • 色钉菇属菌肉多为黄色或橙色，菌丝组织遇梅泽试剂变蓝；铆钉菇属菌褶幼时常有菌幕，菌盖边缘可能残留菌幕碎片，组织非淀粉质
  • 同属内还有易混色钉菇、东方色钉菇、变色色钉菇、紫色钉菇等近似种，形态学特征交叉重叠，仅凭外观有时难以准确鉴定到种
  • 建议采集时结合生境（是否松林）、菌肉颜色及新鲜断面变化等多重特征综合判断，不确定时应交由专业人士辨识
与铆钉菇属的区别
铆钉菇属（Gomphidius）菌褶幼时具菌幕包裹，菌盖边缘常有菌幕残留物；本种（色钉菇属）菌肉呈鲜明橘黄色且遇梅泽试剂变蓝，是最主要的区分依据
属内近似种区别
易混色钉菇（C. confusus）菌盖较小（1–4cm），黄棕色偏红调，囊状体具结晶；本种（C. rutilus）菌盖湿时很黏、光滑，囊状体壁很薄，分布覆盖全国而非局限于西南或东北地区
相似易混淆物种
易混色钉菇 Chroogomphus confusus
同属近似种，菌盖较小（1–4cm），黄棕色带红色色调，囊状体具结晶，主要分布于中国西南部
紫色钉菇 Chroogomphus purpurascens
同属近似种，主要分布于中国东北部，形态与本种相近，需结合产地及显微特征区分
铆钉菇属物种 Gomphidius spp.
同科不同属，外形与本种极其相似，主要靠菌肉颜色（本种为橘黄色）及梅泽试剂反应（本种阳性变蓝）区分，普通采集者较难仅凭肉眼判断
褐黄铆钉菇 Chroogomphus ochraceus（北美分布）
北美同属近似种，形态与本种相近，是分类学文献中常提及的对比物种，我国不产
📖 中文名说明：血红色钉菇 与「红蘑」 Naming Note
名称来源与关系
1
属名 Chroogomphus 由希腊词根 chroo-（颜色）与 Gomphus（钉/楔形，铆钉菇科名称由来）复合而成，中文译作"色钉菇属"；种加词 rutilus 意为"红色的、火红色的"，中文正式名"血红色钉菇"即由此直译而来，突出其红棕至紫红色的菌盖色泽。
2
俗名"红蘑""松树伞""松蘑""肉蘑"：东北地区民间俗称，"红蘑"直指其红棕色菌盖，"松树伞""松蘑"则强调其专性与松树共生的生境特征，"肉蘑"形容其菌肉肥厚的口感；在东北地区是制作传统名菜"小鸡炖蘑菇"的常用食材之一。
3
分类地位：隶属铆钉菇科（Gomphidiaceae）色钉菇属（Chroogomphus），本种为该属的模式种；色钉菇属与铆钉菇属（Gomphidius）虽外形相似，但分子系统学研究证实二者亲缘关系较近，同属牛肝菌目内一支独特的褶菌类群（牛肝菌目中少见的具菌褶物种）。
分布与研究现状
本种在中国全国广泛分布，尤以辽宁丹东、鞍山、抚顺、本溪、铁岭等东部山区油松、赤松纯林中较为常见；国外见于日本、韩国、西伯利亚及欧洲。
近年有研究者对其化学成分与健康促进作用进行系统梳理（发表于Nutrients期刊），提示其在功能性食用菌开发方面具有一定潜力，但相关活性成分的临床验证仍在早期阶段。
🍄 采集提示：本种虽为传统食用菌，但因与铆钉菇属及色钉菇属内多个近似种形态交叉，采集时应仔细核对菌肉颜色、生境（是否松林）等特征；不确定物种时应交由熟悉本地菌类的人士协助辨识后再食用。

群落生境 · 分布采集
生长方式
子实体散生、群生或单生，直接从松林地表根际土壤中长出
生境 · 基质
外生菌根真菌，专性与松属（Pinus）树木根系共生，多见于油松、赤松等纯林或针叶混交林地表，菌丝与树根紧密共生
地区分布
中国全国广布，尤以辽宁东部山区（丹东、鞍山、抚顺、本溪、铁岭）常见；国外分布于欧洲、日本、韩国及西伯利亚
采集季节 · 海拔
夏秋季为主要出菇期，常见于中低海拔松林地区，是北方山区秋季常见的野生食用菌之一
采集建议：优先在明确的松林环境中寻找，注意与铆钉菇属及同属近似种区分；不确定时可通过掰开菌肉观察颜色（本种为橘黄色）辅助判断，但仍建议交由有经验者最终确认。
价值评估
食用价值
传统食用菌，肉质肥嫩、鲜美可口，风味清淡，是东北地区制作"小鸡炖蘑菇"等传统菜肴的常用食材，耐储藏，适合干制保存
药用 / 保健价值
近期研究提示其富含天然活性成分，在功能性食品开发方面具有潜在价值，相关健康促进作用的系统性研究正在推进中，但尚未形成成熟的临床应用
生态价值
作为松属树木的专性外生菌根共生伙伴，在北温带针叶林生态系统的养分循环及松树健康生长中发挥积极作用，是松林生态系统的指示性物种之一
科研与记录价值
作为色钉菇属的模式种，对该属乃至整个铆钉菇科的分类厘定具有基础性参考价值；已被列入《中国生物多样性红色名录—大型真菌卷》，评估等级为无危（LC）
