Dacrymyces stillatus
Nees, 1816 · 英文俗称「Common Jellyspot / Witch's Butter」
◆ 无毒非传统食用菌 橙黄胶质小突起 干缩湿胀反复循环 朽木分解者 全球广泛分布 形态多变待厘清
中文名 花耳（尚无广泛使用的俗称）
英文俗名 Common Jellyspot / Witch's Butter
科 / 属 Dacrymycetaceae 花耳科 / Dacrymyces 花耳属
食用状态 无毒，但体型微小不具食用价值
标志特征：橙黄胶质小点 子实体呈明亮橙黄至黄色的果冻状小突起，直径通常仅1–8毫米，质地滑腻半透明，是雨后朽木上最容易被注意到的"迷你彩点"之一
遇水复原的生存策略 干燥时收缩变硬、颜色暗淡近乎消失，一旦遇雨或环境潮湿便迅速吸水膨胀恢复鲜艳胶质状态，是雨后最早重新"苏醒"的真菌之一
形态多变，待系统厘清 在目前的物种定义下，花耳的形态变化范围很大，被真菌学者认为可能是一个尚待深入研究厘清的物种复合体（species complex）

形态特征 · 生长周期 结构标签
萌发期
子实体从树皮裂缝或去皮木材表面顶出，初为微小的橙黄色点状突起，质地黏滑，尚未形成明显的团块状结构。
发育期
子实体逐渐增大呈垫状（pulvinate）至盘状，表面开始出现不规则的脑状或迂回状皱褶，颜色转为鲜明的橙黄至黄色，质感更加饱满黏滑。
循环期
多个子实体常在潮湿多雨天气融合形成不规则的更大胶质团块；干燥时迅速收缩变硬、颜色暗淡近乎消失，一旦复水又迅速恢复原本鲜艳的胶质状态，如此反复循环，是本种最具观察趣味的生存特征。

各部位详情
部位形态描述
子实体胶质，半透明，橙黄至黄色，垫状至不规则脑状/迂回皱褶状，直径1–8毫米，常多个融合成更大团块
质地新鲜时黏滑柔软，含水量高；干燥后收缩变硬、颜色暗淡，复水后迅速恢复原状，可反复循环多次
子实层直接生长于胶质团块表面，无独立菌褶或菌管等分化结构，孢子直接产生于表面
假柄有时可见不甚明显的假柄结构，但并非所有个体都具备
孢子具隔膜，形态因物种复合体内部差异而有所不同，需借助显微镜辅助鉴定
特殊区分点 反向记忆
核心辨识四要素
  • 子实体呈橙黄至黄色的垫状小突起，直径通常仅数毫米，质地胶质黏滑
  • 表面常具不规则脑状或迂回状皱褶，湿润时最为鲜艳饱满
  • 不具备传统蘑菇的菌盖、菌褶或菌柄分化结构，是"非典型蘑菇"的代表
  • 具有独特的干缩湿胀循环能力，干燥近乎消失、遇水又迅速复原
◆ 食用说明：无毒记录，但缺乏食用意义
  • 目前没有关于本种含有毒素的报道，但同时也没有被认可的食用记录，二者不应混淆——"无毒"不等于"可食"
  • 本种体型极其微小（通常仅数毫米），且质地为几乎全透明的胶质，缺乏实质性的菌肉组织，从营养和口感角度均不具备传统意义上的食用价值
  • 与之相对，同属花耳目、外观颜色相近的桂花耳（Dacryopinax spathularia）体型明显更大、呈匙形或鹿角形，是被认可的食用菌——切勿将本种与近缘可食种混为一谈
  • 本种更适合作为自然观察与真菌科普的对象，而非食材来源
与黄金木耳的区别（不同目）
黄金木耳（Tremella mesenterica，银耳目）外观同为橙黄色胶质，但体型通常更大，形态呈更明显的脑状分裂皱褶；本种体型更小，多呈垫状而非大幅分裂的脑状，是野外初步区分的参考，二者分类地位也不同（分属花耳目与银耳目）
与桂花耳的区别（同目可食种）
桂花耳（Dacryopinax spathularia）同为花耳目，但形态呈匙形或鹿角形而非本种的垫状小点，体型也明显更大（可达1–1.5cm），且是被认可食用、云南丽江俗称"桂花菌"的知名食用菌，与本种的食用价值截然不同
相似易混淆物种
掌状花耳 Dacrymyces palmatus
同属近似种，体型通常更大，形态呈更明显的迂回分裂状，常见于针叶树倒木
黄金木耳 Tremella mesenterica（银耳目）
外观颜色相似均为橙黄色胶质，但分类地位不同（银耳目而非花耳目），体型通常更大且脑状分裂更明显
桂花耳（可食）Dacryopinax spathularia
同目近缘种，但形态呈匙形/鹿角形而非垫状小点，体型明显更大，是被认可的食用菌，云南丽江称"桂花菌"，享有"真菌皇后"美誉
📖 中文名说明：花耳 与「滴落」 Naming Note
名称来源与关系
1
种加词 stillatus 是拉丁文"滴落的"之意，形容其胶质团块含水丰富、外观宛如凝结的水滴或蜜露；属名 Dacrymyces 源自希腊语，意为"泪珠状真菌"，中文属名"花耳"则取意其胶质耳形构造在潮湿时形似鲜艳的小花朵。
2
英文俗名"Witch's Butter"（女巫的黄油）：因其橙黄色黏滑的胶质外观，在英语民间传说中与多种类似的胶质真菌共享这一带有神秘色彩的俗称，常见于欧美地区的自然观察记录中。
3
分类地位：隶属花耳目（Dacrymycetales）花耳科（Dacrymycetaceae）花耳属（Dacrymyces）；花耳目是担子菌门中较为原始的一支，以产生独特的"叉状担子"（音叉状分枝的担子细胞）为标志性显微特征，与银耳目、木耳目等其他胶质真菌类群形成鲜明区分。
命名简史与分布
本种由德国真菌学家尼斯（Christian Gottfried Daniel Nees von Esenbeck）于1816年首次正式描述，是花耳属中被记录最早、分布最广泛的物种之一。
目前已知分布于中国、日本、巴拿马、丹麦、芬兰、俄罗斯、法国、英国、挪威、玻利维亚、美国、荷兰、瑞士、瑞典、新西兰、意大利、德国、墨西哥、澳大利亚等地，是全球温带地区极为常见、四季可见的木材腐生真菌。
🔍 观察提示：雨后或潮湿天气是观察本种的最佳时机，可留意针叶树倒木、去皮枝条及木桩表面的橙黄色小突起；用手轻触会感觉滑腻黏手，是向孩子或初学者演示"真菌如何应对干湿变化"这一生存策略的绝佳自然教育素材。

群落生境 · 分布观察
生长方式
直接从树皮裂缝或去皮木材表面顶出，常密集丛生或融合成不规则团块，附着于基质表面生长
生境 · 基质
木材腐生真菌，生长于阔叶树及针叶树朽木上，尤其偏好针叶树（如松、云杉、冷杉）的去皮倒木及枯枝，也见于人造木质结构表面
地区分布
全球广泛分布，温带地区尤为常见，中国、日本及欧美多国均有记录，是分布范围极广的世界性物种
观察季节
全年可见，但在秋冬季节及雨后潮湿环境中最为显眼饱满，是雨后菌类观察活动中极易发现的入门物种
观察建议：本种是雨后自然观察活动的理想对象，色彩鲜艳、随处可见且无毒安全；建议用手轻触感受其黏滑质地，并对比干燥与湿润状态下的形态差异，体会真菌应对环境变化的独特生存智慧。
价值评估
食用价值
无实际食用价值——虽不含已知毒素，但胶质团块体积微小、缺乏实质菌肉，不具备传统意义上的食用意义
生态价值
木材腐生菌，参与朽木中木质素和纤维素的分解过程，是森林物质循环链条中的基础分解者之一，对维持林地养分循环具有积极作用
科研价值
因形态变化范围极大，被认为是一个尚待系统厘清的物种复合体，对花耳目分类学研究具有重要参考价值；其独特的叉状担子是花耳目的重要鉴定特征
观赏 / 科普价值
色彩鲜艳醒目，全球广泛可见，是自然观察及雨后菌类科普中极具趣味性的入门物种，常被用于展示真菌"干缩湿胀"这一独特的生存策略
